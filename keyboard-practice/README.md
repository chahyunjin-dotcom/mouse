# 손가락 톡톡! 한글 키보드 놀이터 ⌨️

초등학교 1·2학년을 위한 한글 두벌식 키보드 연습 웹앱입니다. 손가락 자리를 보며 한 글쇠씩 익히고, 받침 없는 단어까지 차근차근 연습할 수 있습니다.

## 실행하기

- [웹앱 바로가기](https://toktok-hangul-keyboard-2026.gentlezebu1.chatgpt.site/)
- 또는 이 폴더의 `index.html`을 브라우저로 열어 실행할 수 있습니다.
- 별도 프로그램 설치나 웹앱 내부 회원가입은 필요하지 않습니다.
- **참고:** 위 Sites 주소는 현재 비공개로 설정되어 있어 접속 시 ChatGPT 로그인이 필요할 수 있습니다.

## 연습 단계

1. 🏠 **기본 자리** — 손가락의 기본 위치부터 글쇠마다 5번씩 연습
2. ☁️ **윗줄 자리** — ㅂ·ㅈ·ㄷ·ㄱ 등 윗줄 글쇠를 각 5번 연습
3. 🌱 **아랫줄 자리** — ㅋ·ㅌ·ㅊ·ㅍ 등 아랫줄 글쇠를 각 5번 연습
4. ✨ **Shift 쌍자음** — ㄲ·ㄸ·ㅃ·ㅆ·ㅉ 및 ㅒ·ㅖ 연습
5. 🧩 **받침 없는 단어** — 단어 10개를 각각 2번씩 완성하기

### 받침 없는 단어 10개

| 1~5 | 6~10 |
| --- | --- |
| 🌳 나무 | 🍖 고기 |
| 🌊 바다 | 🦆 오리 |
| 👶 아기 | 🍇 포도 |
| 🧢 모자 | 🦛 하마 |
| 🥛 우유 | 🚂 기차 |

단어는 자음과 모음을 순서대로 누르면 한 글자씩 완성됩니다. 한 단어를 두 번 성공하면 별 2개가 채워지고 다음 단어로 넘어갑니다.

## 주요 기능

- 화면 키보드에 다음 글쇠와 사용할 손가락을 강조 표시
- 실제 키보드 또는 화면 키보드 클릭으로 연습 가능
- Shift 연습 시 반대쪽 손 새끼손가락 사용 안내
- 정확한 입력만 성공 횟수에 반영하고, 실수해도 감점 없음
- 효과음 켜기/끄기, 단계별 별 모으기, 완료 축하 화면
- 브라우저의 로컬 저장소에 연습 진도 자동 저장(같은 기기·브라우저 기준)
- 단계별 **처음부터 다시 연습** 기능

## 파일 구성

- `index.html` — 웹앱 화면과 단계별 연습 영역
- `app.js` — 키보드 입력 판별, 5회 반복, Shift 및 단어 연습 로직
- `styles.css` — 기본 디자인, 키보드와 손가락 그림, 반응형 레이아웃
- `words.css` — 5단계 단어 연습 화면 스타일
- `README.md` — 프로젝트 안내 문서

## GitHub 배포 안내

- 이 폴더는 기존 `mouse` 저장소의 마우스 게임과 분리된 키보드 연습 앱입니다.
- 저장소의 GitHub Actions 워크플로는 `main` 브랜치의 `keyboard-practice/**` 변경을 감지하도록 설정되어 있습니다.
- **GitHub Pages 사용 전:** 저장소 `Settings → Pages → Build and deployment → Source`에서 `GitHub Actions`를 활성화해야 합니다. 현재 GitHub Pages 비활성화로 배포 작업이 실패한 상태입니다.
- 기존 ChatGPT Sites 주소와 GitHub Pages는 별도 배포 환경이므로, GitHub 코드 수정이 기존 Sites 주소에 자동 반영되는 것은 아닙니다.
