# 반짝반짝 마우스 놀이터 🐭

초등학교 1·2학년을 위한 로그인 없는 한글 마우스 연습 웹게임입니다.

## 실행하기

- [웹게임 바로 실행](https://mouse-play-hyeonjin-2026.gentlezebu1.chatgpt.site/)
- 또는 이 폴더의 `index.html`을 브라우저로 열어 실행할 수 있습니다.
- 외부 라이브러리 및 설치가 필요하지 않습니다.

## 미션

1. 별을 콕콕! — 클릭 8회
2. 선물 상자 톡톡! — 더블클릭 6회
3. 로봇 간식 배달! — 드래그 앤 드롭 6회
4. 풍선 팡팡! — 풍선 클릭 12회

미션마다 별 3개, 총 12개를 모으면 마우스 박사가 됩니다.
소리 끄기와 다시 하기 기능이 있습니다. 광고, 로그인, 서버 저장은 없습니다.

## 파일

- `index.html`: 화면 구성
- `style.css`: 디자인과 반응형 레이아웃
- `game.js`: 네 가지 게임 동작

이 GitHub 폴더는 원래 `mouse` 저장소의 기존 게임을 변경하지 않도록 별도로 추가한 버전입니다.

> 참고: 웹게임은 별도 Sites 주소에 배포되어 있으며, GitHub 저장소 변경 사항이 자동으로 사이트에 배포되도록 연결된 것은 아닙니다.
