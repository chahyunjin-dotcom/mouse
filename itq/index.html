시험 시작 전 꼭 확인하세요.

이 화면은 ITQ 시험 절차를 익히기 위한 연습용입니다. 시험장에서는 감독위원의 지시와 해당 시험의 공식 안내를 우선 따라야 합니다.

  • ✓수험표 및 신분 확인 : 감독위원의 지시에 따라 본인 확인을 진행합니다.
  • ✓응시 과목 확인 : 수험표와 문제지에 표시된 시험 과목이 맞는지 확인합니다.
  • ✓답안 저장 : 답안은 지정 폴더 내 PC → 문서 → ITQ에 저장합니다.
  • ✓파일명 확인 : 답안파일 이름은 수험번호-성명 형식으로 만듭니다. 예: 12345678-홍길동.xlsx
  • ✓중간 답안 전송 : 작업 중에도 수시로 저장하고, '답안 전송'으로 제출 여부를 점검합니다.
  • ✓시험 종료 : 마지막 답안 전송 결과를 확인하고 감독위원의 안내에 따라 종료합니다.
※ 본 페이지는 한국생산성본부 공식 시험 프로그램이 아닙니다.
