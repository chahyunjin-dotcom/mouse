# 티처블 머신 AI 가위바위보 — 웹 버전

설치 없이 브라우저에서 플레이하는 AI 가위바위보 게임입니다.

## 접속 링크

https://chahyunjin-dotcom.github.io/mouse/ai-rps/

## 이용 방법

1. 웹페이지에 접속하여 카메라 시작을 클릭하고 권한을 허용합니다.
2. 가위/바위/보를 보여준 뒤 스페이스바 또는 승부 보기 버튼을 누릅니다.
3. 승리, 패배, 무승부 결과를 확인합니다. 점수판은 없습니다.

## 모델 안내

- 모델: https://teachablemachine.withgoogle.com/models/G_tgoTg8a/
- TensorFlow.js 형식을 웹에서 직접 불러와 실행합니다.
- 학습 클래스 이름이 다르면 'AI 클래스 연결 확인' 메뉴에서 직접 매핑해 주세요.

## 주의사항

- 웹캠은 HTTPS 또는 localhost에서 작동합니다.
- 티처블 머신 사이트와 카메라를 동시에 사용하지 마세요.
- 인터넷 접속이 필요하며 웹캠 영상은 서버로 업로드되지 않습니다.
- 소스코드는 index.html 한 파일입니다.
